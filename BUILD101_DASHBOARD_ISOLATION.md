# Build 101 · Dashboard von Fairnis getrennt

Beim Wechsel auf Dashboard wird die vorherige Fairnisansicht sofort entfernt, eine neutrale Dashboard-Ebene gesetzt und anschließend ausschließlich das Dashboard gerendert. Laufzeitfehler werden sichtbar im Dashboardbereich ausgegeben, statt still die vorherige Registeransicht stehen zu lassen.
