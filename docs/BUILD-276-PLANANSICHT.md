# Build 276 RC – Planansicht

Bei 761 bis 1280 Pixel Breite verwendete die senkrechte Werkzeugleiste eine horizontale Flexbasis von 390 Pixel als Höhe des Meldungsbereichs. Der Meldungsbereich erhält in dieser Anordnung eine feste kompakte Höhe und volle Breite. Die Schaltfläche für den eingeklappten Plan zeigt jetzt Plan öffnen statt eines unklaren Symbols. Daten und eingestellte Bereiche bleiben erhalten.
