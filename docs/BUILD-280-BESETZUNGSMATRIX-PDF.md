# Build 280 RC – Besetzungsmatrix als Tages-PDF

PDF direkt an der Bildschirmmatrix: ausgewählter Tag oder alle Tage, je Tag eine Querformatseite. Dokumenttyp Besetzungsmatrix verwendet im Dokumentdialog den aktuellen Arbeitsstand. Druckwerte werden aus derselben matrixHtml-Funktion wie die Bildschirmzellen gewonnen. Keine Änderungen an Plan- oder Mitgliederdaten.
