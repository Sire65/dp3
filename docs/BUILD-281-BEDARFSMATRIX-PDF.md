# Build 281 RC – Bedarfsmatrix direkt als PDF

Druckknopf und Registermenü laden eine echte PDF herunter, ohne Popup. Gleiche Tabelle wie die Bildschirmansicht. Jeder Tag beginnt auf einem eigenen Blatt; lange Tage haben nummerierte Fortsetzungen mit maximal sieben Zeitzeilen, damit der PDF-Renderer keine Zeilen abschneidet. Ungespeicherte Bearbeitung bleibt gesperrt. Keine Änderung der Bedarfs- oder Mitgliederdaten.
