# Build 282 RC – Bedarfsmatrix mit kompaktem Kopf

Kleiner Kopf, Fuß und Erläuterungstext schaffen Platz für einen ganzen üblichen Tag. Tabellen-Schrift 7,8 pt und mindestens 25 pt Zeilenhöhe. Dynamische Zeilenmessung ersetzt die starre Teilung nach sieben Zeilen. Außergewöhnlich lange Inhalte werden weiter auf Folgeseiten verteilt; keine Zeile wird still abgeschnitten.
