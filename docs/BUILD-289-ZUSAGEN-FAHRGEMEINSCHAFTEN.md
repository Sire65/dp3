# Build 289 RC – Zusagen, Fahrgemeinschaften, Fahrtrolle, Erstattung (KICC-F-100 Phase 7)

Twinkey „Bei einem Sondereinsatz helfen“: Zusage (ja/vielleicht/nein), Anreise (ich fahre mit freien Plätzen / brauche Mitfahrt / komme anders hin) und Startort aus Auswahl – keine Adressen. Die eigene Fahrgemeinschaft wird angezeigt. Planer: im Dialog „★ Sondereinsätze“ je Einsatz „👥 Zusagen · 🚗“ mit Übersicht, Vorschlag (gleicher Startort zuerst, Plätze nie überbucht), Umsetzen einzelner Mitfahrer, „✓ Übernehmen und veröffentlichen“ (kc_dp_carpools_publish). Stundenmeldung: Fahrtrolle je Person (Fahrer/Mitfahrer/keine), aus der Fahrgemeinschaft vorbelegt; Hinweis bei mehreren Fahrern. Nach dem Melden „🚗 Fahrtkosten / Auslagen erfassen“ (Club App). Supabase: kc_dp_special_event_signups, kc_dp_carpools, kc_dp_hour_report_reminders, kc_dp_special_event_signups_list, kc_dp_carpools_publish; kc_dp_hour_reports.fahrt_rolle/benachrichtigt_am. Tests: test-special-event-signups, test-twinkey-hours, test-hour-reports-ui.
