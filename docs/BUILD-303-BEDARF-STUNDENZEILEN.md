Keine Lücken erfinden, keine Daten speichern. Drei lesbare Spalten auf A4 quer; zusammenhängender Tag nach Möglichkeit in einer Spalte, weitere Seiten bei Bedarf. Logo, Kopf, Fuß und Personalstunden bleiben erhalten.
